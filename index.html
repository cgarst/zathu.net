MajesticTab

A guitar tab reader that plays every track and jams with other devices on your network.

Opens Guitar Pro (.gp3 .gp4 .gp5 .gpx), PDF, and text tabs. Synthesized playback across every track, an interactive virtual fretboard, a real-time tuner, and multi-device jam mode.

LAN party scripts

Dedicated servers and lobbies on a local network, without defunct master servers or manual setup. Pick a game, copy the command.

GameRepoWhat it does

Provisions dedicated server configurations, handles broadcast IP discovery, patches client profile issues, and brings machines straight into the lobby with no manual network setup. Modes: Gungame, Pistol, RPG, Shotguns, Vanilla.

GitHub 
# Get the scripts:
git clone https://github.com/cgarst/lanscript-cod4.git
cd lanscript-cod4

# Host a LAN game from bin\ (pick a mode):
bin\Launch_Gungame_server.bat

# Join a server on this PC:
bin\Connect_Local_Client.bat
