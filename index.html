MajesticTab

Focused Guitar Tab Reader & Practice Studio

A focused guitar tab viewer engineered for practice sessions. Open Guitar Pro (.gp3/.gp4/.gp5/.gpx), PDF, and text tabs with synthesized playback across every track, an interactive virtual fretboard, real-time tuner, and multi-device jam mode over your local network. Free and open source.

LOCAL NETWORK GAMING

LAN Party Scripts

Automated scripts to configure dedicated servers and connect players on local area networks without relying on defunct master servers or complex manual setup.

lanscript-cod4

Automated LAN party deployment toolkit for Call of Duty 4: Modern Warfare. Seamlessly provisions dedicated server configurations, handles broadcast IP discovery, patches client profile issues, and brings machines straight into the lobby with zero manual network hassle.

Open lanscript-cod4 on GitHub
COD4-LAUNCHER.bat
# Get the scripts: git clone https://github.com/cgarst/lanscript-cod4.git cd lanscript-cod4 # Host a LAN game from bin\ (pick a mode): bin\Launch_Gungame_server.bat # also: Pistol, RPG, Shotguns, Vanilla # Join a server on this PC: bin\Connect_Local_Client.bat

lanscript-cod5

Call of Duty 5: World at War LAN orchestration suite. Powers instant 4-player Nazi Zombies coop sessions and multiplayer matches across airgapped or offline local area networks without relying on defunct authentication servers.

Open lanscript-cod5 on GitHub
COD5-LAUNCHER.bat
# Get the scripts (put retail CoD5 in bin\): git clone https://github.com/cgarst/lanscript-cod5.git cd lanscript-cod5 COD5-LAUNCHER.bat 1. Launch COD WaW for Zombies/Coop 2. Launch COD WaW for Deathmatch/Objectives 3. Change player name

lanscript-quake3

Python-driven LAN party server controller for the undisputed king of arena FPS. Instantly spins up dedicated Quake III instances with configurable tick rates, customized map cycles (q3dm6, q3dm17), weapon respawn timers, and client broadcast beacons.

Open lanscript-quake3 on GitHub
build_server_cfg.py
# Get the scripts: git clone https://github.com/cgarst/lanscript-quake3.git cd lanscript-quake3\bin # Scan baseq3\*.pk3 for maps and build a shuffled rotation: python3 build_server_cfg.py RCON password: 4821 # Wrote baseq3\server.cfg (q3dm17, q3dm1, then random maps)

reclaimer-lan

Project Reclaimer LAN Scripts engineered to bootstrap local multiplayer sessions for classic Halo PC environments. Handles network bridge adapter detection, firewall rule overrides, and custom gametype distribution across LAN nodes.

Open reclaimer-lan on GitHub
start-campaign.ps1
# Get the scripts: git clone https://github.com/cgarst/reclaimer-lan.git cd reclaimer-lan # Download the Project Reclaimer executables: .\update-binaries.ps1 # Start a server (co-op campaign or multiplayer playlist): .\start-campaign.ps1 # or .\start-multiplayer.ps1 LAN players: Direct Connect to 192.168.1.20:12345

CORE VALUES

Design Philosophy

Independent software built for personal use, practical utility, and long-term durability.

The Musician's Bench

Tools like MajesticTab and Setlore are built by musicians for guitar practice, stage setups, and live concert tracking. They run offline, launch quickly, and keep the focus on playing and listening.

The Hacker Craft

Self-hostable, transparent, and released openly. You can read the code, run it on your own hardware, and change it to fit how you work, with no accounts or lock-in.

The LAN & Gamer Spirit

Local multiplayer tools built to keep classic games playable with friends on local networks. Dedicated server automation and streaming launch environments designed for straightforward setup.
